# Markdown to HTML Converter

This is a simple single-page application that converts Markdown text into HTML in real-time using JavaScript, Tailwind CSS, and the Marked.js library.

## Features

-   Real-time Markdown to HTML conversion.
-   Responsive design using Tailwind CSS.
-   Optionally loads content from `input.md` on page load (if present).

## Usage

1.  Open `index.html` in your browser.
2.  Enter Markdown text in the left textarea.
3.  The corresponding HTML output will be displayed in the right div.
4. If an `input.md` file exists in the same directory, its content will automatically load into the Markdown input on page load.

## Technologies Used

-   HTML
-   Tailwind CSS
-   JavaScript
-   [Marked.js](https://github.com/markedjs/marked) (Markdown parser)
